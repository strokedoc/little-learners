# Little Learners

Calm, offline learning games for a 3-year-old: colours, shapes, animals, big & small, counting, and letter tracing.
Built to be deliberately **non-addictive** — see [RULES.md](RULES.md) for the design rules.

**Install on iPhone/iPad:** open the site in Safari → Share → *Add to Home Screen*. Open it once while
online; after that it works with no internet. Grown-up settings are behind the faint ⚙️ (bottom-right).
